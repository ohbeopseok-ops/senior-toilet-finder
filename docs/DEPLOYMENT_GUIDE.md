# 시니어 안심화장실 PWA 실전 배포 & 운영 가이드

본 가이드는 `index.html` 단일 파일을 실제 인터넷상에 0원(무료)으로 배포하고, 어르신들의 스마트폰(Android Chrome, iOS Safari)에 앱 아이콘으로 설치할 수 있도록 돕는 실무 가이드입니다.

---

## 1. 배포 전 필수 지식: 왜 'HTTPS'가 필수인가?

본 서비스의 핵심 기능인 세 가지는 웹 보안 표준상 **HTTPS 보안 연결**에서만 동작합니다:
1. **실시간 위치 추적 (`navigator.geolocation`)**: HTTP에서는 브라우저가 위치 권한 요청을 원천 차단합니다.
2. **PWA 홈 화면 추가 (앱 설치)**: HTTPS 및 Service Worker/Manifest 환경에서만 설치 배너가 트리거됩니다.
3. **음성 합성 (`Web Speech API / SpeechSynthesis`)**: 모바일 브라우저 보안 정책을 충족해야 안정적으로 재생됩니다.

따라서 무료이면서 자동으로 SSL 인증서(HTTPS)를 발급해 주는 호스팅 서비스를 선택해야 합니다.

---

## 2. 5분 완성 무료 배포 방법 (추천 3대 옵션)

### 옵션 A: Vercel (가장 추천 - 3분 컷)
모바일 웹 최적화와 글로벌 CDN, 자동 HTTPS 적용이 가장 뛰어납니다.
1. [Vercel](https://vercel.com)에 가입(GitHub 연동 권장)합니다.
2. 대시보드에서 **Add New... > Project**를 누릅니다.
3. GitHub 저장소를 연결하거나, 로컬 폴더를 드래그 앤 드롭으로 업로드합니다.
4. 배포가 완료되면 `https://your-project.vercel.app` 형태의 고유 HTTPS 주소가 즉시 생성됩니다.

### 옵션 B: Netlify (드래그 앤 드롭 방식)
코드 설정 없이 웹 화면에 폴더만 끌어다 놓아 배포하는 가장 쉬운 방법입니다.
1. [Netlify](https://www.netlify.com)에 로그인합니다.
2. **Sites > Add new site > Deploy manually**를 선택합니다.
3. `index.html`이 담긴 폴더를 브라우저 영역에 드래그 앤 드롭합니다.
4. 즉시 `https://random-name.netlify.app` 주소가 발급되며 배포 완료됩니다.

### 옵션 C: GitHub Pages (소스 코드 공개/오픈소스형)
1. GitHub에 새 저장소(`senior-toilet-finder` 등)를 Public으로 생성합니다.
2. `index.html` 파일을 루트 경로에 업로드하고 커밋합니다.
3. 저장소의 **Settings > Pages** 메뉴로 이동합니다.
4. **Branch**를 `main`(또는 `master`) / `/(root)`로 지정하고 **Save**를 누릅니다.
5. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 주소로 접속 가능합니다.

## 3. 스마트폰 홈 화면 설치(PWA) 확인 방법

### Android (삼성 인터넷 / 크롬)
1. 배포된 HTTPS 주소로 접속합니다.
2. 화면 상단의 **"바탕화면에 큰 아이콘으로 저장"** 배너나 브라우저 하단의 **"홈 화면에 추가"** 팝업을 터치합니다.
3. 바탕화면에 큰 노란색 화장실 아이콘이 생성되며, 이후 주소창 없이 일반 네이티브 앱처럼 전체화면으로 실행됩니다.

### iOS (사파리)
1. 배포된 HTTPS 주소를 Safari 브라우저에서 엽니다.
2. 하단 중앙의 **공유 버튼(네모에 위쪽 화살표 모양)**을 터치합니다.
3. 메뉴를 아래로 내려 **"홈 화면에 추가"**를 터치합니다.
4. 우측 상단 **"추가"**를 누르면 아이폰 홈 화면에 바로가기 앱으로 등록됩니다.

## 4. 공공데이터포털 실제 API 연동 시 체크포인트

현재 프로토타입은 안양천 인근의 실시간 공공데이터 규격 모의 데이터를 탑재하고 있습니다. 실제 공공데이터포털 Open API를 호출하도록 확장할 때 다음 사항을 점검하십시오.

1. **API 활용신청**:
   - [공공데이터포털(data.go.kr)](https://www.data.go.kr) 접속
   - `전국공중화장실표준데이터` 또는 `지자체별 개방화장실 데이터` 검색 후 활용신청 (승인 즉시 일반 인증키 발급)
2. **CORS(Cross-Origin Resource Sharing) 이슈 처리**:
   - 공공데이터포털 API 중 일부는 브라우저(클라이언트)에서 직접 `fetch()` 호출 시 CORS 차단이 발생할 수 있습니다.
   - 해결책: Vercel의 Serverless Function(`/api/toilets.js`) 또는 Cloudflare Worker를 간단한 프록시로 두어 키를 안전하게 숨기고 데이터를 전달받도록 구성합니다.
3. **카카오/네이버 지도 SDK 도입 시**:
   - 카카오 개발자 콘솔 또는 네이버 클라우드 플랫폼에서 **Web 플랫폼 도메인 등록** 필수 (`https://your-project.vercel.app` 등 배포 도메인을 등록해야 지도가 정상 렌더링됩니다).

## 5. 어르신 현장 실증 배포 및 전파 팁

1. **초대형 QR 코드 제작**: 복지관, 경로당, 공원 산책로 입구 게시판 등에 바로 찍을 수 있는 고대비 QR 코드를 인쇄하여 부착합니다.
2. **카카오톡 1:1 전송**: 카카오톡으로 링크를 전달하고 "이 노란 글씨를 누르신 뒤 홈 화면에 추가를 눌러주세요"라는 1분 보조 영상을 제공하면 시니어 진입 장벽을 80% 이상 낮출 수 있습니다.
