# GOLD UAT — 우리 엄마가 10초 안에 화장실 안내를 시작하는가?

## GOLD 정의

**처음 사용하는 시니어 사용자가 화면을 본 순간부터 10초 안에 화장실 안내 화면에 진입하고 음성 안내를 들을 수 있어야 한다.**

- 측정 시작: 앱 첫 화면이 보이는 순간
- 측정 종료: 목적지명 + 거리 + 방향 화면이 표시되고 첫 TTS가 시작되는 순간
- 목표: 10초 이하
- 핵심 터치 수: 설치 후 2회 이하 / 최초 권한 설정 시 5회 이하
- 실패 조건: 글자를 읽지 못함, 위치 권한을 찾지 못함, 뒤로 가기, 10초 초과, 잘못된 화장실 선택, 안내 시작 여부를 인지하지 못함

## A. 최초 1회 설정 GOLD

| 체크 | 기준 | 결과 |
|---|---|---|
| 위치 허용 | 첫 설정 화면에서 3초 안에 '위치 허용'을 찾는다 | ☐ |
| 방향 센서 | 설명 없이 두 번째 버튼을 누를 수 있다 | ☐ |
| 홈 화면 추가 | Safari 공유 → 홈 화면 추가 의미를 이해한다 | ☐ |
| 글자 | 안경 착용 상태에서 모든 주요 문구를 읽는다 | ☐ |
| 버튼 | 한 손 엄지로 오터치 없이 누른다 | ☐ |

## B. 매일 사용하는 핵심 GOLD

1. 홈 화면의 **안심화장실** 아이콘을 누른다.
2. **가장 가까운 화장실 찾기**를 누른다.
3. 10초 안에 **화장실명 / 거리 / 방향 / 음성**이 나온다.

## C. 현장 안전 GOLD

| 항목 | GOLD 기준 |
|---|---|
| 실제 위치 | GPS가 현재 위치를 크게 벗어나지 않는다 |
| 거리 | 표시 거리와 체감 거리가 지나치게 다르지 않다 |
| 개방 여부 | 현장 폐쇄/잠김을 '이용 가능'으로 단정하지 않는다 |
| 계단 | '계단 없음' 표시는 검증된 데이터에만 사용한다 |
| 전화 | 관리기관 번호가 실제 연결되는지 확인한다 |
| 방향 | iPhone 방향 센서 권한 거부 시 잘못된 방향을 확정적으로 표시하지 않는다 |
| 오프라인 | 네트워크 단절 시 fallback 캐시임을 명확히 표시한다 |

## D. 판정

- **GOLD PASS**: 3회 연속 10초 이하 + 첫 시도 성공 + 안전 오판 0건
- **SILVER**: 10~15초 또는 한 번의 도움 필요
- **FAIL**: 15초 초과, 길안내 진입 실패, 안전 관련 오판 1건 이상

## E. 개발자 측정 포인트

앱은 '가장 가까운 화장실 찾기' 터치부터 안내 화면 진입까지 걸린 시간을 브라우저 `localStorage.lastGuidanceStartMs`에 기록한다.

이 값은 UI 성능만 측정한다. **실제 GOLD 10초는 사람이 앱 첫 화면을 본 시점부터 측정**해야 한다.
