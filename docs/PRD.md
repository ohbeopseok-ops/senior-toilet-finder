# [PRD] 시니어 특화 무장애 개방화장실 긴급 안내 서비스 (가칭: 안심화장실)
**Product Requirements Document | Version 1.0 | Target Platform: Mobile Web (PWA)**

---

## 1. 타깃 페르소나 및 핵심 사용자 여정 (User Journey)

### 1.1 타깃 페르소나 (Target Persona)

| 항목 | 상세 내용 |
| :--- | :--- |
| **이름/연령** | 김영호 (만 71세, 남성) |
| **주요 생활 패턴** | 매일 오전/오후 근처 근린공원 및 천변 산책로에서 1~2시간 걷기 운동 수행 |
| **신체적 특성** | - 초기 노안 및 백내장 경향으로 대비가 낮은 작은 글씨(14pt 이하) 판독 불가<br>- 전립선비대증으로 갑작스러운 요의(급박뇨)가 잦아 10분 내 화장실 진입 필수<br>- 무릎 관절염으로 인해 가파른 계단이나 경사로 이용 시 낙상 위험 존재 |
| **디지털 리터러시** | - 카카오톡 기본 메시지 확인 및 유튜브 시청 가능<br>- 복잡한 필터링, 지도 핀치 줌(두 손가락 확대), 텍스트 타이핑 검색에 강한 거부감<br>- 화면 전환이 많거나 로딩이 3초 이상 지속되면 앱을 즉시 종료하는 경향 |

### 1.2 '운동 중 긴급 화장실 탐색' 3단계 원터치 여정 (User Journey)

복잡한 부가 기능을 배제하고, 신체적 긴급 상황에서 **"실행부터 길 안내까지 3회 미만 터치"**로 완료되도록 설계합니다.

```
[1단계: 즉시 진입]
 스마트폰 홈 화면의 '안심화장실' 대형 바로가기(PWA) 1회 터치
       ↓
[2단계: 원터치 탐색]
 화면 중앙 '가장 가까운 화장실 찾기' 초대형 액션 버튼 1회 터치
 (현재 GPS 기반으로 반경 500m 내 '현재 개방 중 + 계단 없는' 최적 화장실 자동 선별)
       ↓
[3단계: 안전 도보 및 음성 안내]
 화살표 중심의 초대형 나침반형 길안내 화면 진입 + 음성(TTS) 즉시 시작
```

## 2. 공공마이데이터 및 공공 API 연계·활용 데이터 명세

### 2.1 공공데이터 및 마이데이터 연계 시나리오

1. **행정안전부 공공데이터포털 연계**
   - **전국공중화장실표준데이터 API**: 전국 공중화장실 기본 제원, 개방시간, 남녀구분, 비상벨 설치 여부 등 확보
   - **지자체별 개방화장실 실시간 현황 API**: 지자체 조례로 지정된 민간/공공 개방화장실 데이터 수집 및 주기적(1일 1회) 정합성 배치 처리
2. **보건복지부 / 행정안전부 공공마이데이터 연계 (선택적 동의 기반)**
   - **장애인 등록증 / 장기요양등급 / 보행약자 정보 연계**: 간편 인증을 통해 보행약자(휠체어, 실버카 이용자) 여부를 1회 확인 후 프로필에 저장.
   - **개인화 필터링 자동 활성화**: 마이데이터 인증 완료 시, 별도 설정 없이도 **'장애인 전용 대변기' 및 '휠체어 리프트/경사로 구비' 시설을 1순위로 자동 가중치 부여**.

### 2.2 핵심 데이터 수집 필드 명세서

| 필드명 (한글) | 시스템 필드명 (Key) | 데이터 타입 | 데이터 출처 | 활용 목적 및 시니어 친화 가공 방식 |
| :--- | :--- | :--- | :--- | :--- |
| **화장실명** | `toilet_name` | String | 공공데이터포털 | 시설명 축약 및 식별성 강화 |
| **위치 좌표** | `latitude`, `longitude` | Float (WGS84) | 공공데이터포털 | 현 위치와의 거리 계산 기준점 |
| **개방 시간** | `open_hours` | String | 공공데이터포털 | 현재 시간 기준 이용 상태 뱃지 생성 |
| **남녀 분리 여부** | `gender_separated` | Boolean | 공공데이터포털 | 남녀 분리 시설 우선 정렬 가중치 |
| **무장애 편의시설** | `barrier_free_info` | Object | 표준데이터 + 지자체 | 경사로, 장애인 대변기, 안전손잡이 |
| **진입로 형태** | `entrance_type` | Enum | 국토교통부 보행로 API | 계단 유무 플래그 |
| **관리기관 연락처** | `manager_tel` | String | 공공데이터포털 | 원클릭 전화 연결 |

## 3. 시니어 특화 UI/UX 설계 가이드

### 3.1 시각 가이드 (Visual & Accessible Design)

* **폰트 및 타이포그래피**
  * 본문 기본 텍스트: **최소 19pt (25px) 이상**
  * 중요 알림/거리 표시: **32pt~44pt Bold**
  * Pretendard GOV, Noto Sans KR 등 가독성 중심 폰트
* **고대비 컬러 팔레트**
  * 배경: `#121212`
  * 강조: `#FFD600`
  * 개방: `#00E676`
  * 종료: `#FF1744`
* **터치 영역**
  * 주요 버튼 세로 64dp 이상
  * 부가 버튼 최소 48dp × 48dp 이상

### 3.2 내비게이션 및 기능 가이드

* 복잡한 지도 마커 군집을 최소화하고 거리·시간·방향 중심으로 안내
* Web Speech Synthesis API 기반 한국어 음성 안내
* 최단거리보다 완만한 경사와 단차가 적은 경로를 우선

## 5. 시스템 아키텍처 및 구현 로드맵

### 기술 스택 방향

- Client: PWA, Tailwind CSS, Geolocation API, DeviceOrientation API, Web Speech
- Map: Kakao Maps 또는 Naver Maps
- Backend: Node.js 또는 Python
- Cache: Redis
- Database: PostgreSQL + PostGIS
- Batch: 공공데이터 정기 동기화

### 4주 MVP 로드맵

1. 데이터 수집/정제 및 개방시간 판별
2. GPS·지도·3단계 사용자 여정 구현
3. TTS·Service Worker·오프라인 캐시 고도화
4. 접근성 검증 및 60대 이상 현장 실증
